# 微信 ↔ Codex 文字聊天桥

**为微信文字聊天连接整理的一套独立安装、授权、启动与诊断工具包。**

连接本机工具时，依赖、网络、授权和服务状态往往需要分开排查。我把这些步骤收进可分享的脚本模板：接收者生成自己的运行目录，使用自己的账号授权，安装后检查手机上的连续收发。

## 分享工具，运行状态留在各自电脑

[New-Bridge.ps1](scripts/New-Bridge.ps1) 从模板生成独立项目。[assets/project/](assets/project/) 包含网络探测、依赖安装、登录、微信配对、启动、停止和状态检查；[故障定位说明](references/troubleshooting.md) 帮助区分网络、授权与服务问题。

预期连接路径是：微信 ClawBot → 微信通道 → 本机 OpenClaw → 使用者自己的 Codex。默认开放文字聊天，服务监听回环地址。登录状态、二维码与聊天记录由个人运行目录保存，可分享仓库只保留模板。

本轮公开整理检查了脚本语法，尚未执行真实安装分支和手机两轮收发。安装指导与实际验证要求见 [SKILL.md](SKILL.md)。

## 使用方式

将仓库放到本机，向自己的 Codex 说明：

```text
请读取这个仓库的 SKILL.md，按说明把我自己的 Codex 接到我自己的微信。
使用独立项目目录，先检查网络和已有安装；需要我登录或扫码时告诉我。
完成后用手机做两轮真实收发和上下文检查，并说明实际验证范围。
```

Windows 有配套 PowerShell 模板。macOS / Linux 的适配方法保留在说明中，本仓库没有声称完成这些系统的实际安装测试。模型、平台入口和账户额度以使用者自己的环境为准。
