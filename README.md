# 微信 ↔ Codex 文字聊天桥

这是我整理的一套微信与本机 Codex 的连接方法和脚本模板。它让使用者在手机微信里和自己的模型连续聊天，安装、配置、启动与排错都收在一个独立项目里。

我把可分享的安装工具包和每个人使用后产生的授权、会话分开。接收者使用自己的账号，不需要拿到分享者的登录状态或聊天记录。

## 包含什么

- `SKILL.md`：给 Codex 的安装与排错入口。
- `scripts/New-Bridge.ps1`：生成独立运行项目。
- `assets/project/`：依赖安装、网络探测、授权、扫码、启动、停止和模型检查脚本。
- `references/`：兼容性、迁移、维护与故障定位说明。

```text
微信 ClawBot → 微信通道 → 本机 OpenClaw → 使用者自己的 Codex
```

默认只开放文字聊天，运行服务监听本机回环地址。账号授权和二维码确认由使用者自己完成；个人运行目录需要保留在本机。

## 使用方式

将仓库放到本机，向自己的 Codex 说明：

```text
请读取这个仓库的 SKILL.md，按说明把我自己的 Codex 接到我自己的微信。
使用独立项目目录，先检查网络和已有安装；需要我登录或扫码时告诉我。
完成后用手机做两轮真实收发和上下文检查，并说明实际验证范围。
```

Windows 有配套 PowerShell 模板。macOS / Linux 的适配方法保留在说明中，本仓库没有声称完成这些系统的实际安装测试。模型、平台入口和账户额度以使用者自己的环境为准。
