# 微信文字聊天助手

此目录是为本机独立生成的项目。安装、授权、微信绑定及实测状态以 Codex 的实际执行记录为准。

- 双击 Start-Bridge.cmd 启动，双击 Stop-Bridge.cmd 停止；Status-Bridge.ps1 查看本机状态。
- 电脑和网络需要保持可用；如果 network.json 使用现有代理，该代理也需要运行。
- 默认没有开机自启。电脑重启后需要再次启动。
- Login-ChatGPT.ps1 是模型账号授权，Pair-WeChat.ps1 是微信扫码绑定。这是两个不同步骤。
- 助手配置为文字聊天，工具被禁用。使用同一 ChatGPT 账号不代表导入 Codex 桌面中的对话和记忆。
- 使用现有账户的 Codex 权益及额度；不能承诺免费无限量。此项目没有配置 API 密钥回退。
- state 包含登录凭据和会话，日志可能包含私人消息。分享安装方法时应分享原技能包，不要压缩这个运行目录。
- 模型与 OpenClaw 的变化可能要求重新核对配置；不要无条件执行升级。

如果失败，把原始错误和当前停在哪一步告诉 Codex；不要把密码、授权码或令牌发给别人。
