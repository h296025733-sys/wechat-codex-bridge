# 续跑、调整与停用

## 中断后继续

读取项目 .bridge-project.json、SETUP-STATUS.md（如果存在）、Check-Auth、Status-Bridge 及最近一次实际失败日志。文件缺失只说明那一步没有记录，不能自动等于失败。

- 已生成的非空项目不重新运行初始化器。
- 已安装且版本符合的组件由安装器检查后保留；改安装前先停该项目，不能中断别人的服务。
- 已有有效本人 OAuth 时跳过网页登录，先做真实请求。
- 已绑定微信且通道正常时跳过扫码；从缺失的手机验证继续。
- 用户新消息如果只是“已授权”“没看到二维码”“收到回复了”，把它当作当前阶段的状态反馈，继续原搭建任务，不从头开始。

## 更换模型

先确认用户要的模型在该账号的 Codex 路由可用，并核对当前模型目录和原生命令帮助。修改模型主选择和对应 models 条目的 agentRuntime=codex；保持无 API 回退和聊天权限。只修改本项目，必要时停止并启动。模型变更后重新执行两轮本地模型验证和一次微信回复验证，明确新的实际模型及可能的额度、延迟变化。

不要仅改展示名或在提示词里写“你是某某模型”，那不会证明后端已切换。

## 更换账号或电脑

已有授权和微信绑定属于原先选择的账号。用户明确要求换账号时，先确认要替换哪个项目；核对当前原生登录/退出/解绑帮助后再操作。对于不同人的账号，优先创建独立项目并让本人授权，避免混淆身份和会话。不要对用户全局 Codex 执行 logout 来修复单个 OpenClaw 项目。

迁移到新电脑时，分享原技能包，重新检测环境并由接收者授权。运行项目含绝对路径、系统相关依赖及凭据，不是可直接跨机转发的安装包。移动同机目录前先停止，核对配置中的 workspace/logging 和进程记录，再验证当地安装路径；没有迁移需求时不要擅自移动。

## 启动与停用

默认保持用户已授权的本地后台进程，不自动创建开机自启、服务或计划任务。用户另行要求常驻/自启时，再依据操作系统提供可查看、可停用的方案，并在实际重启/重连前后核对，不把“创建任务成功”当作重启后回复成功。

停止使用只需运行 Stop-Bridge。用户要求删除时，先确认停止的是该项目，再核对目标绝对路径和项目标记；只删除明确要求的项目目录，不删除系统 Node、全局 Codex 或其他项目。备份也包含授权，应由用户妥善保管。取消微信绑定与删除本机文件是不同动作，按用户实际要求处理。
